# IranYekan UI fonts

PBM expects these three licensed/local font files in this directory:

- `iranyekanwebregular.woff`
- `iranyekanwebmedium.woff`
- `iranyekanwebbold.woff`

Use `scripts/personal/install-ui-fonts.ps1` to copy your original WOFF files into this directory with the expected names. Font binaries are intentionally not committed by the assistant.
